# 포트폴리오 웹사이트 (Portfolio)

이정연의 개인 포트폴리오 웹사이트입니다. 콘텐츠 기획과 UI/UX 디자인 프로젝트를 소개하는 반응형 정적 웹사이트로, HTML5, CSS3, 바닐라 JavaScript를 활용해 제작했습니다.

## 프로젝트 개요
- **제작자:** 이정연
- **분야:** 콘텐츠 기획자 · 디지털 크리에이터
- **기술 스택:** HTML5, CSS3, Vanilla JavaScript
- **프로젝트 유형:** 반응형 개인 포트폴리오 웹사이트

## 주요 구성 및 기능
1. **고정 상단 내비게이션 & 스크롤 진행률 바:** PC·모바일 반응형 헤더 및 햄버거 메뉴
2. **풀스크린 히어로 섹션:** 전체 화면 배경 이미지와 자기소개 문구
3. **프로젝트 섹션 (3개 카드):** 브랜드 전략, UI/UX 디자인, 웹 매거진 프로젝트 카드
4. **Contact 폼:** 입력값 유효성 검사 및 전송 완료 토스트 알림

## 파일 구조
```text
portfolio/
├── index.html   # 메인 HTML 구조
├── styles.css   # 반응형 레이아웃 및 스타일시트
├── script.js    # 스크롤 진행률, 모바일 메뉴, 폼 유효성 검사
└── README.md    # 프로젝트 설명 문서
```
